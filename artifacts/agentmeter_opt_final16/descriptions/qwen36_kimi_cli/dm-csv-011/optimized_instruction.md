# dm-csv-011

**Type**: Data Manipulation
**Difficulty**: Hard

## Task

Calculate the total quantity sold and total sales revenue for each bike category from 2016 to 2018. Ensure that total sales revenue accounts for any discounts applied to each order. 

Write the results into `/app/output/result.csv`. The output must strictly follow the exact structure, column names (`total_quantity`, `total_price`, `category_name`), and formatting of the template file located at `/app/data/sample_result.csv`.

## Environment

- Input data files are in `/app/data/` (including `sample_result.csv`).
- Save your output file to `/app/output/` with the exact filename: `result.csv`.
- Python packages available: pandas, numpy, scipy, scikit-learn, statsmodels, matplotlib.
