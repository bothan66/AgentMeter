            # dm-csv-011

            **Type**: Data Manipulation
            **Difficulty**: Hard

            ## Task

            Calculate the total quantity sold and total sales revenue for each bike category from 2016 to 2018. Ensure that total sales revenue accounts for any discounts applied to each order. Write the results into result.csv, following the exact structure and formatting of sample_result.csv.

            ## Environment

            - Input data files are in `/app/data/`
            - Save your output file(s) to `/app/output/` with the exact filename(s): `result.csv`
- Python packages available: pandas, numpy, scipy, scikit-learn, statsmodels, matplotlib
